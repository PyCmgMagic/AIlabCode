## 详细功能说明

### 1. main.py
**功能**：主控制脚本，提供交互式菜单
**用法**：
```bash
python main.py              # 交互模式
python main.py --auto 5     # 自动运行完整流程
```

**菜单选项**：
- 1: 准备数据集
- 2: 训练所有模型
- 3: 验证所有模型
- 4: 生成可视化图表
- 5: 运行完整流程
- 6: 快速实验

### 2. train_all_experiments.py
**功能**：训练7个不同配置的YOLO模型
**实验配置**：
- 实验1: Nano基线 (epochs=50, batch=16)
- 实验2: Small基线 (epochs=50, batch=16)
- 实验3: Nano + batch=8
- 实验4: Nano + lr0=0.001
- 实验5: Nano + AdamW
- 实验6: Nano + 数据增强
- 实验7: Nano + 组合优化

**输出**：
- runs/detect/exp*/ - 模型和训练结果
- experiment_log.json - 实验记录

**预计时间**：2-4小时

### 3. train_quick.py
**功能**：快速训练3个模型用于测试
**配置**：前3个实验，epochs=30
**预计时间**：1-2小时

### 4. validate_all_models.py
**功能**：验证所有训练好的模型
**输出指标**（7个）：
1. mAP50 - AP at IoU=0.5
2. mAP50-95 - AP at IoU=0.5:0.95
3. mAP75 - AP at IoU=0.75
4. Precision - 精确率
5. Recall - 召回率
6. F1-Score - F1分数
7. Fitness - 综合适应度

**输出文件**：
- validation_results.json
- validation_results.csv

### 5. visualize_results.py
**功能**：生成6种对比图表
**输出图表**：
1. metrics_comparison.png - 6指标对比柱状图
2. radar_chart.png - 性能雷达图
3. model_size_comparison.png - 模型大小对比
4. hyperparameter_impact.png - 超参数影响
5. top_models_ranking.png - 性能排名
6. summary_table.png - 结果汇总表

**输出目录**：visualization_results/

### 6. analyze_training.py
**功能**：分析训练过程曲线
**输出图表**：
- exp*_curves.png - 每个实验的6指标训练曲线
  - Loss曲线
  - mAP曲线
  - Precision & Recall
  - 学习率变化
  - 验证Loss
  - 统计信息
- comparison_curves.png - 多实验对比

**输出目录**：training_curves/

### 7. analyze_hyperparameters.py
**功能**：深度分析超参数影响
**输出图表**：
1. batch_size_impact.png - 批次大小影响
2. learning_rate_impact.png - 学习率影响
3. optimizer_impact.png - 优化器影响
4. augmentation_impact.png - 数据增强影响
5. impact_summary_table.png - 影响汇总表

**输出目录**：hyperparameter_analysis/

### 8. prepare_data.py
**功能**：从NFS挂载点划分数据集
**配置**：
- 训练集：随机选取（总数-55）张
- 验证集：随机选取55张
- 确保训练集和验证集无重复

**输出**：my_dataset/ 目录

### 9. distribution_box.yaml
**功能**：YOLO数据集配置文件
**内容**：
```yaml
path: /mnt/nfsdir/DistributionBoxUnclosed
train: images/train
val: images/val
nc: 1
names:
  0: unclosed
```

### 10. requirements.txt
**功能**：Python依赖列表
**主要依赖**：
- ultralytics>=8.0.0
- pandas>=1.5.0
- matplotlib>=3.5.0
- torch>=2.0.0

## 使用流程

### 标准流程
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备数据
python prepare_data.py

# 3. 训练模型
python train_all_experiments.py

# 4. 验证模型
python validate_all_models.py

# 5. 基础可视化
python visualize_results.py

# 6. 训练曲线分析（可选）
python analyze_training.py

# 7. 超参数分析（可选）
python analyze_hyperparameters.py
```

### 快速流程
```bash
python main.py
# 选择 6: 快速实验
```

## 满足实验要求检查

✅ **1. 训练两个不同尺寸的模型**
- Nano模型 (yolo11n)
- Small模型 (yolo11s)

✅ **2. 修改至少4个超参数**
- batch (16 → 8)
- lr0 (0.01 → 0.001)
- optimizer (SGD → AdamW)
- 数据增强 (hsv_h, hsv_s, hsv_v, degrees)

✅ **3. 使用至少5个指标评价**
- mAP50
- mAP50-95
- Precision
- Recall
- F1-Score
- (额外: mAP75, Fitness)

✅ **4. 对比修改前后影响**
- 所有可视化脚本都包含对比分析
- 超参数影响分析详细展示变化百分比

✅ **5. 可视化图表**
- 共生成19+张图表
- 涵盖性能对比、训练过程、超参数影响
