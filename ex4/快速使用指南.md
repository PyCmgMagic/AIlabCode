# 实验四快速使用指南

## 一、环境准备

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 挂载数据集（如果使用NFS）

```bash
# 安装NFS客户端
sudo apt install nfs-common

# 创建挂载目录
sudo mkdir -p /mnt/nfsdir

# 挂载NFS
sudo mount 172.26.1.21:/mnt/diska /mnt/nfsdir
```

### 3. 准备数据集

```bash
python prepare_data.py
```

这将从NFS挂载点划分出训练集和验证集（验证集55张图片）。

## 二、运行实验（三种方式）

### 方式1：使用主控脚本（最简单）

```bash
python main.py
```

按照菜单提示操作即可。

### 方式2：快速测试（推荐初学者）

如果想快速测试流程，只训练3个模型：

```bash
# 1. 快速训练
python train_quick.py

# 2. 验证
python validate_all_models.py

# 3. 可视化
python visualize_results.py
```

### 方式3：完整实验

训练全部7个实验配置：

```bash
# 1. 训练所有模型（耗时较长，2-4小时）
python train_all_experiments.py

# 2. 验证所有模型
python validate_all_models.py

# 3. 生成基础可视化图表
python visualize_results.py

# 4. 分析训练曲线（可选）
python analyze_training.py

# 5. 深度分析超参数影响（可选）
python analyze_hyperparameters.py
```

## 三、输出文件说明

### 训练输出

- `runs/detect/exp*/` - 每个实验的详细结果
  - `weights/best.pt` - 最佳模型权重
  - `weights/last.pt` - 最后一个epoch的权重
  - `results.csv` - 训练过程数据
  - `confusion_matrix.png` - 混淆矩阵
  - `F1_curve.png` - F1曲线
  - `PR_curve.png` - PR曲线
  - `P_curve.png` - Precision曲线
  - `R_curve.png` - Recall曲线

### 验证输出

- `validation_results.json` - 详细验证结果（JSON格式）
- `validation_results.csv` - 验证结果表格（可用Excel打开）

- `visualization_results/` - 基础对比图表
  - `metrics_comparison.png` - 6指标对比图
  - `radar_chart.png` - 性能雷达图
  - `model_size_comparison.png` - 模型大小对比
  - `hyperparameter_impact.png` - 超参数影响
  - `top_models_ranking.png` - 性能排名
  - `summary_table.png` - 汇总表格

- `training_curves/` - 训练曲线
  - `exp*_curves.png` - 各实验训练曲线
  - `comparison_curves.png` - 多实验对比曲线

- `hyperparameter_analysis/` - 超参数深度分析
  - `batch_size_impact.png` - 批次大小影响
  - `learning_rate_impact.png` - 学习率影响
  - `optimizer_impact.png` - 优化器影响
  - `augmentation_impact.png` - 数据增强影响

## 四、实验报告撰写

### 需要的图表和数据

1. **实验设置**
   - 使用 README.md 中的实验配置表
   - 说明修改的4个超参数

2. **性能对比**
   - 使用 `validation_results.csv` 中的数据
   - 插入 `visualization_results/metrics_comparison.png`
   - 插入 `visualization_results/top_models_ranking.png`

3. **模型对比**
   - 插入 `visualization_results/model_size_comparison.png`
   - 插入 `visualization_results/radar_chart.png`

4. **超参数影响**
   - 插入 `hyperparameter_analysis/` 中的所有图表
   - 使用 `hyperparameter_analysis/impact_summary_table.png`

5. **训练过程**
   - 插入 `training_curves/comparison_curves.png`
   - 选择1-2个代表性的 `training_curves/exp*_curves.png`

### 至少5个指标

从 `validation_results.csv` 中获取：
1. mAP50
2. mAP50-95
3. Precision
4. Recall
5. F1-Score
6. mAP75（可选）
7. Fitness（可选）

### 问题与解决方案（至少2个）

示例：

**问题1: GPU内存不足**
- 现象：训练时出现CUDA out of memory错误
- 原因：批次大小太大
- 解决：将batch从16减小到8
- 代码：在训练脚本中设置 `batch=8`

**问题2: 模型过拟合**
- 现象：训练集loss很低，但验证集loss很高
- 原因：数据增强不足
- 解决：增加数据增强参数（hsv_h, hsv_s, degrees等）
- 代码：设置 `hsv_h=0.02, hsv_s=0.8, degrees=15.0`

**问题3: 训练不稳定**
- 现象：loss波动很大
- 原因：学习率过高
- 解决：降低初始学习率
- 代码：设置 `lr0=0.001`

**问题4: 收敛速度慢**
- 现象：需要很多epoch才能达到较好效果
- 原因：优化器选择不当
- 解决：改用AdamW优化器
- 代码：设置 `optimizer='AdamW'`

## 五、常见问题FAQ

### Q1: 如何查看训练进度？

训练时会在终端输出进度，也可以使用TensorBoard：

```bash
tensorboard --logdir runs/detect
# 访问 http://localhost:6006
```

### Q2: 训练时间太长怎么办？

可以：
1. 减少epochs：改为30或20
2. 使用快速训练脚本：`python train_quick.py`
3. 只训练Nano模型，不训练Small模型

### Q3: 如何修改数据集路径？

编辑 `distribution_box.yaml` 文件：

```yaml
path: /your/dataset/path
```

### Q4: 如何添加自己的实验配置？

在 `train_all_experiments.py` 中添加：

```python
train_model(
    model_size='n',
    config_name='my_experiment',
    **BASE_PARAMS,
    epochs=50,
    batch=16,
    # 你的超参数
    name='exp_my_experiment'
)
```

### Q5: 可以用CPU训练吗？

可以，但会很慢。修改脚本中的：

```python
device=0  # 改为
device='cpu'
```
