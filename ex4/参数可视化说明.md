# 参数影响可视化 - 实验报告专用图表说明

## 功能介绍

`visualize_parameter_effects.py` 是专门为实验报告设计的高质量参数影响可视化脚本，生成7张详细的分析图表，展示超参数调整对模型性能的影响。

## 快速使用

### 方法1：使用主控脚本（推荐）

```bash
python main.py
# 选择 5: 生成参数影响详细图表
```

### 方法2：直接运行

```bash
# 前提：已完成训练和验证
python visualize_parameter_effects.py
```

## 生成的7张图表详解

### 📊 图表1：参数对比网格 (parameter_comparison_grid.png)

**用途**：一目了然看到各个参数调整的效果

**内容**：
- 2x2网格布局，展示4个超参数的影响
- 每个子图包含：
  - 基线配置 vs 修改后配置的柱状图对比
  - 数值标注
  - 变化百分比（带颜色箭头）
- 性能区间背景色提示

**适用场景**：实验报告的"超参数影响对比"章节

---

### 🔥 图表2：变化百分比热力图 (change_percentage_heatmap.png)

**用途**：清晰展示哪些参数对哪些指标影响最大

**内容**：
- 横轴：6个评估指标（mAP50, mAP50-95, mAP75, Precision, Recall, F1）
- 纵轴：5个参数配置
- 颜色：
  - 绿色 = 性能提升
  - 红色 = 性能下降
  - 黄色 = 无明显变化
- 每个单元格标注具体变化百分比

**适用场景**：实验报告的"参数敏感性分析"章节

---

### 📈 图表3：参数敏感性分析 (parameter_sensitivity.png)

**用途**：排名各参数的影响程度

**内容**：
- 水平条形图，按影响程度从大到小排序
- 显示平均影响百分比
- 附带各指标的详细变化数据

**适用场景**：实验报告的"结论"章节，说明哪些参数最重要

---

### 🔄 图表4：修改前后详细对比 (before_after_comparison.png)

**用途**：详细展示每个参数修改前后的变化

**内容**：
- 4个参数的对比，每个参数包含：
  - 上半部分：5个指标的柱状图对比（修改前 vs 修改后）
  - 下半部分：变化百分比柱状图
  - 平均改善百分比标注

**适用场景**：实验报告的"超参数调整结果"章节

---

### 🎯 图表5：组合优化效果 (combined_effect_analysis.png)

**用途**：展示多参数组合优化的效果

**内容**：
- 左图：单独优化 vs 组合优化的平均提升对比
- 右图：组合优化在各指标上的具体表现
- 突出显示组合优化的综合效果

**适用场景**：实验报告的"组合优化分析"章节

---

### 📏 图表6：模型尺寸详细对比 (model_size_comparison_detailed.png)

**用途**：对比Nano和Small模型的性能差异

**内容**：
- 左图：各指标柱状图直接对比
- 中图：Small相对Nano的提升百分比
- 右图：雷达图对比（视觉化展示整体性能）

**适用场景**：实验报告的"模型选择分析"章节

---

### 📋 图表7：综合总结报告 (comprehensive_summary.png)

**用途**：全面总结所有实验结果

**内容**：
- 上半部分（2x3网格）：5个指标的所有配置对比
  - 最佳配置用绿色高亮
- 右侧：平均性能提升排名
- 底部：实验总结文本
  - 总实验数
  - 最佳配置
  - 参数影响排序

**适用场景**：实验报告的"实验结果总结"章节，作为总览图

## 常见问题

### Q1: 图表中文显示乱码？

修改脚本开头：
```python
matplotlib.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
```

根据系统选择可用字体。

### Q2: 如何修改图表尺寸？

修改 `figsize` 参数：
```python
fig, axes = plt.subplots(figsize=(18, 12))  # (宽, 高) 单位：英寸
```

### Q3: 如何导出为其他格式？

修改保存格式：
```python
plt.savefig(output_path.replace('.png', '.pdf'), ...)  # PDF格式
plt.savefig(output_path.replace('.png', '.svg'), ...)  # SVG格式
```

### Q4: 某些实验未完成，图表显示不全？

脚本会自动跳过未完成的实验，只显示已完成的部分。
